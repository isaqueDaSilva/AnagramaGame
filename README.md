# Como executar o programa

1. Crie e ative o ambiente virtual para o projeto:

   Siga as instruções contidas no link: [https://docs.python.org/pt-br/3/library/venv.html](https://docs.python.org/pt-br/3/library/venv.html) para criar e ativar o ambiente virtual.

2. Instale as dependências do projeto:

   pip install -r requirements.txt

4. Execute o programa:

   python game.py (ou python3 game.py, dependendo da sua instalação do Python)
